# Tutorials

Tutorials teach VUEDA through one task at a time, from an empty start to a working result. They assume you know Django, Django REST framework, and Vue ([What you need to know](start-building#what-you-need-to-know)). To do one specific thing in a project you already have, use the [Guides](/guides/).

## Getting Started

- [Start Building](start-building.md): Scaffold a new VUEDA project, add an inventory model to its Django API, and use it from the Vue client.
- [Add Workflow to a Model](add-workflow.md): Wire up workflow URLs, enable workflow on a model, create its states and transitions, grant workflow permissions, and verify the API and client.
