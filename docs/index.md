# VUEDA

Welcome to the Vue.js User Experience for Django Administration (VUEDA) documentation!

## What is VUEDA?
VUEDA is an open-source project that offers a `djangorestframework`-based alternative to `django-admin`, for building modern, user-friendly admin interfaces using `Django` and `Vue.js`.

## What is available here?
This documentation provides comprehensive information about VUEDA, including how to get started, detailed guides on various features, core concepts, and reference materials.

This documentation is organized into four main sections:
- [**Start Building**](/start-building/): Step-by-step guides to help you get started with VUEDA and learn how to use its features effectively.
- [**Guides**](/guides/): In-depth articles covering specific topics and use cases to help you make the most of VUEDA.
- [**Core Concepts**](/core-concepts/): Detailed explanations of VUEDA's architecture, philosophy, components, and underlying technologies.
- [**Reference**](/reference/): Comprehensive reference materials including the Changelog, Glossary, REST, Python and JavaScript API reference, Vue.js Components reference, and more.
