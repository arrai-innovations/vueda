# Changelog

These changelogs track integrator-facing package changes. They are split by package because client and server versions can move independently below the major version.

## Packages

- [Client](client.md): Changes for the `@arrai-innovations/vueda` npm package.
- [Server](server.md): Changes for the `vueda` Python package.

Each page starts its public history at the first v3 beta: client v3.0.0-beta.1 and server v3.0.0b1. The section for that beta describes the release as a whole. Each later section lists the changes since the previous published version. A project on VUEDA v2 follows [Upgrade from VUEDA v2](../../guides/upgrade-from-v2.md).

## Reading Version Notes

Use the docs footer to confirm which client and server versions this documentation build describes. Docs tags control publishing, but they are not a third public changelog.

Package changelog entries should focus on changes that affect consuming applications. Pure documentation edits, prose corrections, and internal docs tooling changes usually do not need entries here.
