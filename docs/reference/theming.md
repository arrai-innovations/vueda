# Theming

The default theme, `@vueda/theme/vueda-tailwind`, has two generated reference pages:

- [Theme keys]{@api theming:keys}: each component's theme slots and the classes that the default theme gives them.
- [Theme tokens]{@api theming:tokens}: the CSS custom properties that `base.css` defines, with their light and dark values.
