- **Delete and bulk action views load the selected rows through the `lookup` filter**:
    - `ViewDestroy`, `ViewSelectedObjectsAction`, and `ModelActionForm` request the selected rows with one `lookup` query value per object key instead of with the `id` filter. The server's `VuedaFilterSet` adds the `lookup` filter in the same release that reports `lookup_field` in model info.
      _Upgrade the `vueda` server package to that release. Build each viewset's filterset on `VuedaFilterSet`, or add `LookupInFilterSet` to a filterset that is built on another class._
