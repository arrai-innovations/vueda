- **Update requests from `useObjectForm`**:
    - An update takes its URL from the object instance's `pk`, which `defaultObjectUpdate` reads from its new `pk` argument. The request body holds the form values, or the values that `submitFields` selects, plus the primary key when the caller passes the new `primaryKeyField` and `primaryKey` props, as `ViewUpdate` does.
      _Read the URL value from `pk` in a custom update adapter. Pass `primaryKeyField` and `primaryKey` to `useObjectForm` when an update body must carry the primary key._
