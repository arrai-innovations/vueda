- **Project views in `src/views` replace VUEDA's views**:
    - Each built-in action, such as `list`, now renders the project's `src/views/View<Name><App><Model>.vue`, then `src/views/View<Name>.vue`, before VUEDA's view. A custom action or transition without its own view now renders `src/views/ViewAction.vue` or `src/views/ViewExecuteTransition.vue` before VUEDA's view. A `setCrudComponents` entry still replaces this lookup for its action, and [View Component Resolution Order](../../core-concepts/routing-and-view-resolution-model.md#view-component-resolution-order) lists every file name.
      _Rename any existing `src/views` file that matches one of these names but is not meant to replace a VUEDA view, such as `ViewList.vue` or `ViewAction.vue`._
