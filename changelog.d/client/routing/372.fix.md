- **CRUD routes open when workflow discovery is denied (`requireModelInfo`)**:
    - A user whom the server denied workflow discovery for a model (a `403` from the permitted transitions request) was redirected away from every route of that model, including list and read routes the API serves them. The guard now decides CRUD routes from model info and `routeActions` alone, and redirects with the "Permission Denied" toast only on a transition route. The workflow store still records the denial.
