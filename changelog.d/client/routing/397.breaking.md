- **Multi-object routes carry one `pk` query value per key (`getCRUDForTo`, `makeCRUDRoutes`)**:
    - A list route for several objects now uses `?pk=4&pk=7`, and its `query.pk` is an array instead of a comma-separated string. The route passes each value to the view whole, so composite keys arrive intact and `?pk=4,7` now selects the single key `4,7`. `getCRUDForTo` throws when its `query` argument has a `pk` entry.
