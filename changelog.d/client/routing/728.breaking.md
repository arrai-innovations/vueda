- **The built-in update form no longer sends the object key in the request body**:
    - The update form passes the edited object's key to the update adapter as `pk` and sends only the submitted fields in the body. `defaultObjectUpdate` puts `pk` in the request URL, and it reads the key from the object's `pkKey` field only when `pk` is omitted.
      _Update a custom update adapter to read the object key from `pk`. Update server code that reads the key from an update request body to read it from the URL._
