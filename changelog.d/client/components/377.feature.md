- **Theme class merging**:
    - The built-in Tailwind theme now replaces conflicting default utilities through `theme-override` and `patchTheme`, while preserving explicit `false` removals and utilities for different properties.
    - Other themes can register their own class conflict rules with `setClassMerger`; core does not import the Tailwind merger.
      _Use `theme-override` to replace theme classes; a plain `class` prop remains additive. Apply project patches after the relevant defaults register; see [theming and customization](../../core-concepts/theming-and-customization#how-the-layers-interact)._
