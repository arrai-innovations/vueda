- **Action views call extra actions at their routed URL, with a method that the action accepts**:
    - `ViewAction` and `ModelActionForm` send an extra action to the `urlPath` that model info reports. They send `PUT` when the action's `methodNames` lists `put`, and otherwise the first write method that it lists. When model info gives an action no write method, `ViewAction`, `ViewDestroy`, `ViewActivate`, and `ViewDeactivate` disable the confirm button and tell the user that only viewing is permitted.
