- **`ViewAction` and `ModelActionForm` call extra actions at their routed URL**:
    - The action views now send an extra action to the `urlPath` that model info reports, with a method that the action accepts. They send `PUT` when the action's `methodNames` lists `put`, and otherwise the first write method that it lists. An action without `PUT`, or with a custom `url_path`, previously failed from its action page.
      _Upgrade the `vueda` server package to the release that reports `url_path` in `model_actions`. With an older server, an action whose name has a dash goes to a URL that the router does not serve._
