- **`FieldSetSingularStackedInline` shows a saved object on update forms**:
    - Since `client-v3.0.0-beta.1`, an update form could show an empty unsaved row in place of a singular inline's saved object. This happened when the inline's field objects loaded or changed after the record. The inline now auto-creates an empty object only when its field holds no object. A create form still starts with an empty object when the inline is required or has `autoCreateWhenEmpty`.
