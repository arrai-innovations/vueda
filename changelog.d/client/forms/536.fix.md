- **Rows of a read-only inline are read-only on create and update forms**:
    - When `expandable_fields` declares a relation `read_only`, or `fieldProps` sets `readOnly: true` on an inline, every input in the inline's rows now renders read-only. Before, the rows stayed editable, and the server dropped the edited values without an error. This holds for the stacked, singular stacked, and tabular layouts.
      _To keep one sub-field editable inside a read-only inline, set `readOnly: false` on its dotted name, such as `fieldProps: { "lines.note": { readOnly: false } }`._
