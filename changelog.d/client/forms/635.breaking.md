- **Action views send only a method that model info lists for the action**:
    - `ModelActionForm` and the action views built on it send an action only with a write method that the action's `methodNames` in model info lists. The `requestMethod` prop now chooses among those methods instead of overriding them, and it no longer defaults to `PUT`. Without such a method, the form disables the confirm button and sends no request.
      _A host that renders `ModelActionForm` for an endpoint missing from model info, such as a route without `@action`, must pass `run-action` to send the request._
