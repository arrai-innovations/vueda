- **File uploads and nested form values**:
    - Create, update, and patch detect files inside nested values and send `Blob` content as a file; multipart saves preserve arrays, objects, nulls, empty collections, `false`, and `0`.
    - Unsupported multipart values, including `undefined` and custom class instances, raise an error naming their path before sending.
      _Deploy the server's nested multipart support before upgrading the client; custom backends must implement the [multipart format](/core-concepts/crud-adapter-layer#file-detection-and-formdata-encoding)._
