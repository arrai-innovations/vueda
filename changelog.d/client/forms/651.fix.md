- **Combobox labels and selection for number values with string options**:
    - `WidgetCombobox` matches a selected value to an option when both have the same string form. A number primary key now matches the string option value from a choices endpoint. The closed field shows the option's label, and the open list checks the option. In multiple selection, clicking a selected option deselects it instead of adding it a second time.
    - Picking an option whose value matches the field's current or initial value keeps that value's own form. The field does not become modified when the user picks the value that it already had.
    - The widget context has a new `initialValue` state property. It holds the field's initial value from the field context, and it is `undefined` without a field context.
