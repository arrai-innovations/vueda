- **Combobox labels and selection for number values with string options**:
    - `WidgetCombobox` now matches a selected value to an option when both have the same string form, such as a number primary key and the string value from a choices endpoint. The closed field shows the option's label, the open list checks it, and clicking it in multiple selection deselects it instead of adding it again. Picking the value that the field already has keeps that value's own form, so the field does not become modified.
