- **`ViewExecuteTransition` names the states and skips refused records**:
    - The banner names the transition's target state and the states that the selected records are in, and a record that the server refuses is skipped instead of blocking the confirm. A record refused only because another request held its row lock stays in the next confirm, because the same confirm can succeed once the lock is released. `ModelActionForm` takes the new `skippedPks` and `pkNotices` props, labels the confirm button with the count that it runs on, such as "Approve (2 of 3)", and shows an already-there record's message through the new `info` severity of `FieldMessage`.
