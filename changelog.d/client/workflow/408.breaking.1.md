- **`historyWorkflowStateHistory` URL default**:
    - The default becomes `/routes/vueda.history/workflow-state-history/:app/:model/:pk/`, the path where the server serves the workflow state history when `vueda.history.urls` is included in `routes/`.
      _Include `vueda.history.urls` in the `routes/` path that includes `vueda.workflow.urls`. If you mount it elsewhere, call `setCustomUrl("historyWorkflowStateHistory", ...)` with that path. See [Add Workflow to a Model](../../tutorials/add-workflow.md#wire-up-workflow-urls)._
