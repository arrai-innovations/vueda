- **`executeTransition` resolves a bulk run to `target_state` and `objects`**:
    - A bulk run resolves to the transition's `target_state` and an `objects` map keyed by primary key, which holds each object's state before the run and its result. Its `FormValidationError` still keys each refused object's errors by primary key, and `responseData` keeps the whole body.
      _Code that reads a bulk result by primary key at the top level must read `objects` instead._
