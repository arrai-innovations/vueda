- **`storeUser.currentUserRequestStatus` replaces `initialized`, `init()`, and `initializingPromise`**:
    - `storeUser.currentUserRequestStatus` holds `loading`, `error`, and `errored` for the current-user request alone, so another action's failure does not change it. `loading` is `undefined` before the first request, `true` while one runs, and `false` once it finishes. `errored` says whether the finished request failed.
      _Replace `initialized` with `currentUserRequestStatus.loading === false && !currentUserRequestStatus.errored`, and calls to `init()` with `waitForCurrentUser(pinia)` from `@vueda/router/guards.js`._
