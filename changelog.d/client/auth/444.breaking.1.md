- **`storeUser.authPendingFlow` replaces `pendingFlow` and `recentlyLoggedIn`**:
    - `storeUser.pendingFlow` is renamed to `authPendingFlow` and holds the flow id string, such as `"mfa_authenticate"`, instead of an object with an `id`. Each who-is response sets it from the server's `auth_pending_flow`. `storeUser.recentlyLoggedIn` is removed: a signed-in user with no `authPendingFlow` has recently authenticated.
      _Replace `pendingFlow?.id` with `authPendingFlow`, and `recentlyLoggedIn` with `loggedIn && !authPendingFlow`._
