- **Forgot password and reset password views (`ViewForgotPassword`, `ViewResetPassword`)**:
    - `ViewForgotPassword` requests a reset link for an email address. `ViewResetPassword`, the page the emailed link opens, checks the link, asks for a new password, and offers a new link when the server rejects it. `ViewSignIn` shows a "Forgot password?" link when `forgotPasswordTo` names a route, and `storeUser`'s password reset actions now default to the `vueda.user` routes.
      _To use them, route `ViewForgotPassword` and `ViewResetPassword`, passing the reset link's `pk` path parameter and `token` query value as props; the integrator templates show the routes._
