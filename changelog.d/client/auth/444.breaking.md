- **Second-factor reauthentication (`ViewReauthenticate`, `storeUser`, `ViewTwoFactorAuth`)**:
    - `ViewReauthenticate` renders a code form or a password form as the account requires, and `storeUser.twoFactorReauthenticate` confirms a code through `2fa/reauthenticate/`. For a signed-in user, each who-is response sets `storeUser.pendingFlow` to `mfa_reauthenticate` or `reauthenticate` while the session is not recent. `ViewTwoFactorAuth` accepts a `runAction` attribute in place of its sign-in submit.
      _Mount `ViewReauthenticate` at the route named `reauthenticate`; a re-authentication view that only asks for the password strands users who have a device. See [Build Auth Views](../../guides/build-auth-views.md#build-a-re-authentication-view)._
