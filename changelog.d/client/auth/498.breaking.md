- **`AuthForm` redirects to reauthenticate on open**:
    - `AuthForm` and `useAuthFlow` send a user whose session has a reauthentication flow pending to the `reauthenticate` route as soon as the form opens, not only after the server refuses a submission. A refused submission that finds the user signed out sends them to the route named `sign-in`. Both take a `requireRecentAuth` option that defaults to `true`.
      _Set `requireRecentAuth` to `false` on any `AuthForm` whose action the server accepts without a recent session. Apps that render `AuthForm` need a route named `sign-in`._
