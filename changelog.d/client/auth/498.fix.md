- **`AuthForm` reauthentication redirects**:
    - A refused submission that leaves a reauthentication flow pending now sends the user to the `reauthenticate` route once, with one toast, and a form that opens while that flow is pending redirects too. A refused submission that finds the user signed out sends them to the route named `sign-in`, and any other `UnauthorizedError`goes to the form's usual error handling. `ViewChangePassword` no longer redirects to `reauthenticate`, because the server does not require a recent session to change the password.
      _Apps that render `AuthForm` need a route named `sign-in`._
