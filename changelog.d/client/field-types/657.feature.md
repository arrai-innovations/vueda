- **Email and URL fields as links in read views and lists (`EmailDisplay`, `UrlDisplay`)**:
    - `WidgetEmailReadOnly` and `ColumnEmail` show an email address as a `mailto:` link, and `WidgetUrlReadOnly` and `ColumnUrl` show an `http` or `https` URL as a link. Any other value shows as text, and an empty value shows a dash. These columns render their own link, so a list whose `detailLinkField` names an email or URL column no longer has a row link.
      _To keep a row link on such a list, point `detailLinkField` at another column._
