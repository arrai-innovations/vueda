- **Email and URL fields as links in read views and lists (`WidgetEmailReadOnly`, `WidgetUrlReadOnly`, `ColumnEmail`, `ColumnUrl`)**:
    - A read view and a list cell show an email address as a `mailto:` link and an `http` or `https` URL as a link. The new `EmailDisplay` and `UrlDisplay` render them. Any other value shows as text, and an empty value shows a dash.
    - These adapters keep their own link, so a list whose `detailLinkField` names an email or URL column has no row link. Point `detailLinkField` at another column to keep one.
