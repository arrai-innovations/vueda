- **`WidgetDuration` reads and writes the server's duration value**:
    - The value is the duration string a `DurationField` sends and reads, such as `1 02:30:00`. The widget used to write an object with one entry per unit, which a `DurationField` rejected, and it showed a saved string value as empty spinners.
    - The new `seconds` prop makes the value a number of seconds, and `DurationSecondsField` fields set it, so they send the integer that field reads.
    - The shown units split the value between them, so two days read as 48 hours when days are hidden. Clearing a unit while the rest of the value is zero sets the value to `null`.
      _Bind a `WidgetDuration` placed by hand to a duration string or, with `seconds`, a number of seconds, instead of a `{ days, hours, minutes, seconds }` object. See [Form Widgets](../../reference/components/widgets.md#duration)._
