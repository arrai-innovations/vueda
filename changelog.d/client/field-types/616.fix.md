- **`WidgetHtml` values match what the user did**:
    - Clearing the editor now sets the field to `""` instead of `<p></p>`. A field that loaded empty and that the user clears again is no longer modified. A required field that the user clears now fails the required check. Toolbar buttons are disabled while the widget is disabled, so they no longer change a disabled field's value. A value that changes before the editor mounts now appears in the editor. The widget no longer registers Underline twice, so the duplicate-extension warning is gone.
      _`@tiptap/extension-underline` is no longer a client dependency. Applications that import it directly must add it to their own dependencies._
