- **Serializer field subclasses use the stock field's mappings**:
    - A field whose serializer class subclasses a stock field, such as a `ManyRelatedField` subclass, now gets the stock field's widget, column, props, and initial value from `typeSerializerAncestors`. Before, an editable form failed with "No widget component found" for such a field. An entry mapped for the subclass's own name still wins. A reverse foreign key declared with a `ManyRelatedField` subclass now renders read-only, the same as one declared with `ManyRelatedField`.
