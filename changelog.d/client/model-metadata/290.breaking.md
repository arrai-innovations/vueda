- **Top-level model info keys are camelCase (`storeModelInfo`, `useModelInfo`)**:
    - Model info from `storeModelInfo` and `useModelInfo` now camelCases every top-level key. `app_label` is now `appLabel`, `verbose_name` is now `verboseName`, `verbose_name_plural` is now `verboseNamePlural`, and `workflow_enabled` is now `workflowEnabled`. Keys inside `fields`, `filtering`, and `expand` are unchanged.
    - Destroy and model action confirmations now name the model by its verbose name, such as "purchase order", instead of its slug, such as "purchaseorder".
      _Rename these keys wherever your code reads model info from the store or seeds it in tests and fixtures. The server response keeps its snake_case keys._
