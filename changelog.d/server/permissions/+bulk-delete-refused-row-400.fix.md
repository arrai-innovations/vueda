- **Bulk delete answers the per-pk 400 when an object check refuses a row**:
    - A bulk delete (`DELETE` on a list route with `pks`) answered `404 Not found` for the whole request when an object-level check refused a row by raising `Http404` or Django's `PermissionDenied`. That happens when a row-level instance check denies both `delete` and `read`, or when a viewset's `check_object_permissions` override raises Django's exception. The request now answers the documented `400`, naming the refused pk with the same "Object with pk=... does not exist." message as a missing pk. Nothing is deleted in either case.
