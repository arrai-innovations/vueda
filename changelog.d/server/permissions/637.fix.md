- **Model info access**:
    - Model info for a model answers a signed-in user who may perform at least one action on the model, and the model list holds only those models. Model info needs no `contenttypes` permission, so a user with every permission on a model gets its model info instead of `403`. A user who holds only `contenttypes.read_contenttype` and `contenttypes.list_contenttype` gets `403` and an empty list.
