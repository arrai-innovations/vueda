- **Nested writes enforce related-row permissions**:
    - Forward foreign-key, forward one-to-one, and many-to-many mutations now require the related model's registered viewset permissions, including object and workflow-state checks.
    - Pk-only entries link without invoking related save hooks; unknown pks return 400 instead of creating rows.
      _Register a canonical viewset for each related model you mutate and grant the required create or update permissions; use pk-only entries when linking existing rows. See [nested-write permissions](../../guides/nested-writable-inlines#permissions-for-related-rows)._
