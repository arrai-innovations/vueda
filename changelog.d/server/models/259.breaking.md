- **`vueda_core.E019` replaces `vueda_info.E009` and checks every manager that does not annotate `formatted_name`**:
    - `vueda_info.E009` checked only the default manager, only on models that a registered serializer reached, and only when the model set `formatted_name = None` on its own class. `vueda_core.E019` is a model check, so it covers every installed model that reaches `formatted_name` through `formatted_name_lookup_expression`, and it reports each of the model's managers by name, not only the default. It reads the queryset each manager builds, so a manager of your own that annotates `formatted_name` passes whatever it inherits.
      _`manage.py check` can now report models that it passed before, and Django stops `migrate` and `runserver` on a system check error. Fix a reported manager by subclassing `FormattedNameManager`, or opt a non-default manager out with `used_without_formatted_name = True` ([opt-out rules](../../guides/create-crudl-surface.md#opting-a-manager-out-of-the-check)). Replace `vueda_info.E009` with `vueda_core.E019` in `SILENCED_SYSTEM_CHECKS` or anywhere else you match the check by id._
