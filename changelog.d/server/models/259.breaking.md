- **`vueda_core.E019` replaces `vueda_info.E009` for a default manager that does not annotate `formatted_name`**:
    - `vueda_info.E009` checked only models that a registered serializer reached, and only when the model set `formatted_name = None` on its own class. `vueda_core.E019` is a model check, so it covers every installed model that reaches `formatted_name` through `formatted_name_lookup_expression`, including one that inherits `formatted_name = None` from an abstract base. It reads the queryset the default manager builds, so a manager of your own that annotates `formatted_name` passes whatever it inherits.
      _`manage.py check` can now report models that it passed before, and Django stops `migrate` and `runserver` on a system check error. Fix the default manager by subclassing `FormattedNameManager`, or by pointing `Meta.default_manager_name` at a manager that annotates `formatted_name`. Replace `vueda_info.E009` with `vueda_core.E019` in `SILENCED_SYSTEM_CHECKS` or anywhere else you match the check by id._
