- **`used_without_formatted_name` opts a manager out of the `formatted_name` manager check**:
    - Set `used_without_formatted_name = True` on a manager other than the default when nothing orders, filters, or serializes its querysets by `formatted_name`, such as a manager that feeds a data export. `vueda_core.E020` still reports that manager when the model's `Meta.ordering` needs `formatted_name`, because Django applies that ordering to every manager. [Data That VUEDA Does Not Display](../../guides/data-vueda-does-not-display.md) compares the opt-out with using a plain Django model.
