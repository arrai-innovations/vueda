- **`VuedaFilterSet` reserves the `lookup` filter name**:
    - The client's delete and bulk action views load the selected rows through the `lookup` filter that `VuedaFilterSet` adds. System check `vueda_info.E018` reports a `VuedaFilterSet` subclass that declares, removes, or replaces the `lookup` filter, including through `Meta.fields` or `Meta.exclude` on a model field named `lookup`.
      _Rename any filter that a `VuedaFilterSet` subclass names `lookup`, and give the filter of a model field named `lookup` another name._
