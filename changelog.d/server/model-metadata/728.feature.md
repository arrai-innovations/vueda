- **Viewsets with a custom `lookup_field`**:
    - Model info reports each model's `lookup_field`, and detail routes, bulk `pks` bodies, and the workflow and workflow state history endpoints identify an object by that field's value. Every `VuedaFilterSet` adds a hidden `lookup` filter that matches the object keys that a request repeats, as in `?lookup=A&lookup=B`. System check `vueda_info.E017` rejects a canonical viewset whose `lookup_field` is not a unique, non-null field that its serializer returns, and [Primary Key and Identifier Discipline](../../core-concepts/pk-and-identifier-discipline.md#lookup-field-and-object-key) describes the contract.
