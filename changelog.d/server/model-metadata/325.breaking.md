- **Filter type of value-derived filters in model info**:
    - `model_filtering` reports `type_filter` as `AllValuesChoiceField` for an `AllValuesFilter` and `AllValuesMultipleChoiceField` for an `AllValuesMultipleFilter`. These filters build the same form fields as `ChoiceFilter` and `MultipleChoiceFilter`, so they used to report `ChoiceField` and `MultipleChoiceField`, and a client could not tell their fetched choices from listed ones by type.
      _Update any client code that reads `type_filter` to handle the two new types. See [Filter Input Types](../../core-concepts/filtering-and-ordering-semantics.md#filter-input-types)._
