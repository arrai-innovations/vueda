- **Detail action parameters follow the viewset's lookup URL keyword**:
    - Each detail action in `model_actions` lists `parameters` that start with the viewset's lookup URL keyword, `lookup_url_kwarg` or `lookup_field`, followed by the arguments that an extra action's `url_path` captures. `VuedaViewSet.detail_args` and `VuedaReadOnlyViewSet.detail_args` are removed. `VuedaViewSet.history_list` and the `activate` and `deactivate` actions of `DeactivateActionViewSetMixin` take the URL keyword through `**kwargs` instead of a `pk` argument.
      _Remove any `detail_args` override, and pass the URL keyword by name when an override calls one of these methods through `super()`._
