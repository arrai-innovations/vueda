- **`PrimaryKeyListSerializer` and `ModelPrimaryKeyValueField` are renamed**:
    - `vueda.core.serializers.PrimaryKeyListSerializer` is now `ObjectKeyListSerializer`, and `ModelPrimaryKeyValueField` is now `ObjectKeyField`, because each entry they convert is an object key: the value of the viewset's `lookup_field`. Their validation messages now say "object keys", and a bulk request that names a missing or refused object answers `Object with key <key> does not exist.`
      _Import the new names, and update code or tests that match the old messages._
