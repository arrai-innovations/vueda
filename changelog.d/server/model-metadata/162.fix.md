- **`ExcludeFieldsSerializerMixin` outside a ViewSet request**:
    - The mixin raised `KeyError: 'view'` when its serializer was built without a view, such as in `/info/` for a `get_field_model_info` override that read `self.fields`. It now excludes no fields there, and `vueda_core.E009` is removed, so a serializer registered with `register_serializer()` may use the mixin. On a DRF view that is not a ViewSet, such as `UpdateAPIView`, the mixin raises `ImproperlyConfigured` instead of `AttributeError`, and the new `vueda_core.E021` check reports that view.
