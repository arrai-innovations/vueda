- **Serializer checks reach serializers passed to `as_view()`**:
    - The `vueda_core.E001` to `vueda_core.E008` checks now also check a serializer passed as `serializer_class` to `as_view()`, including one that `@action(serializer_class=...)` sets for an extra action. A misconfigured serializer used only that way passed `manage.py check` before and now reports an error.
      _If `manage.py check` reports a new error after upgrading, fix the serializer that it names._
