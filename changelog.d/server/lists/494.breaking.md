- **`ordering_fields_from_path` renamed to `ordering_path_field` (`vueda.core.ordering`)**:
    - It returns the one field that describes the value that a path sorts by, instead of the list of fields that the path traverses. Django's own `Query` resolves the path, so a path that ends in a transform resolves too.
      _Import `ordering_path_field`, and use its return value where you used the last item of the old list._
- **`vueda_info.E006` reports annotation names that contain a dot or a comma**:
    - A viewset `ordering` term or `ordering_fields` entry that names an annotation containing `.` or `,` used to pass the system checks. A `JSONField` key with either character was already reported. It now stops `manage.py check`, because the client sends dotted `?o=` names and no request can name it.
      _Annotate the value under a name without a dot or a comma, and order by that name._
