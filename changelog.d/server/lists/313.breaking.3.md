- **A column total over no rows is `0`, not `null`**:
    - `ListRowLevelViewSetMixin.get_column_info` now aggregates each total with a zero `default`, so a filter matching no rows totals `0` where `SUM` would otherwise return SQL `NULL`. Every value in a `columnTotals` response is a number, which is what the paginated response schema has always declared, and a client no longer has to tell "no rows" apart from "no total".
    - The zero matches the column being summed, because Django hands an aggregate's `default` to `Value(default, <the aggregate's output field>)`. `DurationField` is the only summable column that is not a number, so a duration total falls back to a zero `timedelta` and everything else to `0`. The column is resolved from the model once per process rather than per request.
      _A client that special-cased a null total can drop that branch. A viewset overriding `get_column_info` keeps whatever its own `aggregate()` call produces._
