- **`nulls_ordering` keys that no list request can sort by**:
    - The `vueda_info.E007` system check now reports a `nulls_ordering` key or `nulls_ordering_flip` entry that names no field the viewset can be sorted by. A dotted key such as `"customer.user.email"`, or a field missing from `ordering_fields` and the default ordering, used to pass the checks while its nulls placement was never applied. The check stops `runserver`, `migrate`, and the other management commands until it is fixed.
      _Write each key `__`-joined, as in `ordering`, and make sure `ordering_fields` or the default ordering names it._
