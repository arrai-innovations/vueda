- **`nulls_ordering` keys that no list request can sort by**:
    - The `vueda_info.E007` system check now reports a `nulls_ordering` key or `nulls_ordering_flip` entry that names no field the viewset can be sorted by. A dotted key such as `"customer.user.email"`, or a field missing from `ordering_fields` and the default ordering, used to pass the checks while its nulls placement was never applied. The check stops `runserver`, `migrate`, and the other management commands until it is fixed.
      _Write each key `__`-joined, as in `ordering`, and make sure `ordering_fields` or the default ordering names it._
- **A `nulls_ordering` key on a `pk` path applies to the field behind it**:
    - A placement keyed on a `pk` path, such as `{"option_type__pk": "first"}`, now also applies to the field behind it. That covers a `?o=option_type.id` request and a default `ordering = ["option_type__id"]`. Before, it applied only to the `pk` spelling. `model_ordering` advertises the `.id` spelling, so the VUEDA client never sent a request that the placement applied to. After the upgrade, those lists put null rows where the declaration says, which can be the other end from before.
      _Check each `nulls_ordering` key and `nulls_ordering_flip` entry that names a `pk` path. Change or remove it if null rows should stay where they were._
- **A `nulls_ordering` key on a composite primary key must name each column**:
    - The `vueda_info.E007` system check now reports a `nulls_ordering` key or `nulls_ordering_flip` entry on the `pk` of a composite primary key when the same attribute leaves out any of the key's columns. `model_ordering` advertises each column separately, so a client sorts by one column at a time. A placement on the `pk` applies only when the list is sorted by the whole key. The check stops `runserver`, `migrate`, and the other management commands until it is fixed.
      _Add each column of the key to the same attribute, with the same placement, such as `{"order_item__pk": "first", "order_item__order": "first", "order_item__product": "first"}`._
