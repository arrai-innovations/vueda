- **`NoExtraFieldsForViewSetMixin` recognizes the totals parameter only where it is read**:
    - `get_extra_allowed_fields()` is now an instance method rather than a `@staticmethod`, and includes `COLUMN_TOTALS_PARAM` only when the viewset also carries `ListRowLevelViewSetMixin` (detected as `get_declared_column_totals`). That mixin's `list` is what validates the names the parameter carries and answers 400 for an undeclared one, so a viewset with strict parameters and no totals reader used to accept `?ct=anything` and silently do nothing with it, which is the hole the mixin exists to close. Such a viewset now rejects the parameter like any other unrecognized one.
      _Call it on an instance rather than the class if you call it directly. A viewset that carries both mixins is unaffected, and so is one that overrides the method._
