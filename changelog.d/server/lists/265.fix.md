- **Search on a queryset that carries an aggregate**:
    - `VuedaSearchFilterBackend` now keeps the joins of a search field that reaches through a reverse foreign key or a many-to-many inside subqueries, and narrows the viewset's queryset to the matching objects. A queryset annotated with an aggregate such as `Sum` or `Count` now lists and counts correctly under a ranked (`V:`) search, which previously failed the request with `NotImplementedError: annotate() + distinct(fields) is not implemented`. Under a `#` or `~` search the same aggregate now counts each object's rows once, where the search's join used to multiply it.
