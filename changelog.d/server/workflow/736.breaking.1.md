- **Workflow migrations that run before `vueda_workflow` `0008` are skipped**:
    - `updatevuedamigrations` reports such a migration as skipped and leaves it unchanged, because it has to keep the functions that it was written with. A skipped migration does not change the exit status, where `updateworkflowmigrations` counted it as a failure.
      _If a script relied on that failure, check the command's `Skipping:` lines instead._
