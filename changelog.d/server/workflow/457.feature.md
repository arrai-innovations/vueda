- **Generated migration `changed_data` formatting**:
    - `makeworkflowmigrations`, `updateworkflowmigrations`, and `makegroupmigrations` format `changed_data` with black or ruff when one is installed, following the project's settings, with each change and key on its own line. black is preferred when the project configures it in `[tool.black]`. Without either, or when the formatter fails, the commands write a narrow `pprint` layout, printing the formatter's error so you can fix it and format the migration by hand. See [how `changed_data` is formatted](../../guides/manage-workflows.md#how-changed-data-is-formatted).
