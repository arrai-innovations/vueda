- **Workflow migration updates**:
    - `updateworkflowmigrations` leaves migrations unchanged when their dependencies lack the workflow event schema its current functions need. It reports those files as failures, including in `--dry-run` mode, while updating compatible files.
      _Review skipped migrations using the [workflow migration guide](../../guides/manage-workflows.md#migrations-the-command-must-not-rewrite). Restore any files broken by an earlier rewrite from version control before running the command again._
