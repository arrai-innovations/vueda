- **Workflow models no longer show an empty "Valid Transitions" row**:
    - `valid_transitions` now sets `style={"hidden": True}`, so model info reports it as `hidden` and the client's default read and update views leave it out. The detail views still request it for their transition buttons. Default list requests no longer fetch it either.
      _Custom list code that reads `valid_transitions` from list rows must name the field in that view's `fetchFields`._
