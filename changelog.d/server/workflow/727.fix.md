- **Object states follow every change to a workflow's initial state**:
    - Generated workflow migrations and `backfillworkflowstates` read objects through the model's base manager, so a default manager that hides rows no longer leaves objects without a state. An object state that was created in the initial state of that moment, and that nobody has moved since, now follows every change to the initial state, and `backfillworkflowstates` moves it too. An object state created in another state, such as by an import, stays there.
