- **Object states follow every change to a workflow's initial state, and the sync reaches every object**:
    - Generated workflow migrations and `backfillworkflowstates` now read objects through the model's base manager. A default manager that hides rows no longer leaves those objects without a state. An object that nobody has moved now goes to the new initial state each time the initial state changes, not only the first time.
      _`backfillworkflowstates` now also moves each untouched object state to the workflow's current initial state. An object state is untouched when it was created in the initial state of that moment and nobody has moved it since. An object state created in another state, such as by an import, stays there._
