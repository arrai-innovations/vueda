- **Reversing a workflow migration keeps object states**:
    - Reversing any generated workflow migration deleted the object states of every workflow in the project. A reversal now changes only the workflows it names, and returns each object in a removed state to its previous state. `migrate` prints what the reversal changed for each workflow.
      _Run `updateworkflowmigrations` on your apps to give their workflow migrations the new reverse code ([workflow migration guide](../../guides/manage-workflows.md#reversing-a-workflow-migration))._
