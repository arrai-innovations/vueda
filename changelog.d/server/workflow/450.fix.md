- **`updateworkflowmigrations` app selection**:
    - `updateworkflowmigrations` updates only apps in your project's source tree. With no app label it ignores apps installed as packages, such as `vueda_vdq`, and naming one exits with status 2 without changing any file. See [which apps a run covers](../../guides/manage-workflows.md#which-apps-a-run-covers).
