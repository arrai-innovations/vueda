- **`updateworkflowmigrations` app selection**:
    - `updateworkflowmigrations` updates only apps in your project's source tree. It never rewrites apps installed as packages, such as `vueda_vdq`, and naming one exits with status 2 without changing any file. It still reads their migrations, both to keep each workflow reference naming the workflow it meant and to check dependencies. See [which apps a run covers](../../guides/manage-workflows.md#which-apps-a-run-covers).
