- **Bulk transition refusals say which objects need no change or can retry**:
    - `check_transition` raises `AlreadyInTargetStateError`, a subclass of `InvalidTransitionError`, when it refuses an object that is already in the transition's target state. A bulk execute-transition `400` adds `already_in_target_state: true` to that object's entry, and `locked: true` to the entry of an object whose row lock another request held. The default refusal messages now name the transition and states, such as "Pack Order is not available from the Shipped state."
