- **`updatevuedamigrations` replaces `updategroupmigrations` and `updateworkflowmigrations`**:
    - One command refreshes every generated group and workflow migration with the functions and imports that `makevuedamigrations` writes now. It always covers every app and takes no app labels, and it never rewrites an app installed as a package. It removes functions and imports that VUEDA no longer writes when nothing else uses them, and it reports a migration that needs no change as already up to date.
      _Replace both commands with `updatevuedamigrations` in your scripts and docs. See [Updating Existing Workflow Migrations](../../guides/manage-workflows.md#updating-existing-workflow-migrations)._
