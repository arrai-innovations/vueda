- **`updatevuedamigrations` replaces `updategroupmigrations` and `updateworkflowmigrations`**:
    - One command refreshes every generated group and workflow migration with the functions and imports that `makevuedamigrations` writes now. It always covers every app, so it takes no app labels. Apps installed as packages are read but never rewritten. It removes functions and imports that VUEDA no longer writes when nothing else in the migration uses them, and it reports a migration that needs no change as already up to date.
      _Replace both commands with `updatevuedamigrations` in your scripts and docs. See [Updating Existing Workflow Migrations](../../guides/manage-workflows.md#updating-existing-workflow-migrations)._
