- **The `--import-instead` option is removed**:
    - A migration made with `--import-instead` imports its functions from the removed `makegroupmigrations` and `makeworkflowmigrations` command modules, so `migrate` and `makemigrations` fail with `ModuleNotFoundError`. The option was meant for VUEDA's own tests, not for project migrations.
      _Run `updatevuedamigrations`, which replaces those imports with copies of the functions. For a workflow migration that runs before `vueda_workflow` `0008`, the command names the file instead: replace each import with a copy of the function as it was when the migration was made._
