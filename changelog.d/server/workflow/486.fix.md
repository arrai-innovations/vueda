- **Reversing a workflow migration after trigger or model option changes**:
    - Reversing a generated workflow migration could fail with `ValueError: Cannot query "Workflow object (…)": Must be "Workflow" instance.` when the reversal left applied a later migration that changes model options or triggers, such as adding pghistory triggers. The reverse code now rebuilds the models Django gives it, working around [Django ticket #33586](https://code.djangoproject.com/ticket/33586). The `vueda_vdq` workflow migrations include the fix.
      _Run `updateworkflowmigrations` on your apps to give their workflow migrations the new reverse code ([workflow migration guide](../../guides/manage-workflows.md#reversing-a-workflow-migration)). Migrations made with `--import-instead` get the fix when you upgrade._
