- **`makevuedamigrations` replaces `makegroupmigrations` and `makeworkflowmigrations`**:
    - One command writes group and workflow migrations in the order of your changes, and each migration depends on the ones before it. It checks every app, so it takes no app labels, and `--debug` is now `--workflow-debug`. A new migration's name ends in 8 random hex characters instead of a date, such as `0005_workflow_migrations_3f9a2c71`.
      _Replace both commands with `makevuedamigrations` in your scripts and docs. See [Generating Workflow Migrations](../../guides/manage-workflows.md#generating-workflow-migrations)._
