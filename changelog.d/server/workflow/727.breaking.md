- **`makevuedamigrations` replaces `makegroupmigrations` and `makeworkflowmigrations`**:
    - One command now writes group and workflow migrations in the order of your changes, and each migration depends on the ones before it. It checks every app, so it takes no app labels, and `--debug` is now `--workflow-debug`. New migration names no longer end in a date.
      _Replace both commands with `makevuedamigrations` in your scripts and docs. See [Generating Workflow Migrations](../../guides/manage-workflows.md#generating-workflow-migrations)._
