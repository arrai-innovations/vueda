- **`makevuedamigrations` replaces `makegroupmigrations` and `makeworkflowmigrations`**:
    - One command now writes group and workflow migrations in the order of your changes, and each migration depends on the ones before it. It checks every app, so it takes no app labels, and `--debug` is now `--workflow-debug`. New migration names no longer end in a date. A new migration's name ends in a random suffix of 8 hex characters instead, such as `0005_workflow_migrations_3f9a2c71`.
      _Replace both commands with `makevuedamigrations` in your scripts and docs. See [Generating Workflow Migrations](../../guides/manage-workflows.md#generating-workflow-migrations)._
    - The `--import-instead` option is removed. A migration made with it imports its functions from the removed command modules, so `migrate` and `makemigrations` fail with `ModuleNotFoundError`.
      _In each such migration, change the imports from `vueda.workflow.management.commands.makeworkflowmigrations` to `vueda.workflow.migration_generation.operations`, and those from `vueda.user.management.commands.makegroupmigrations` to `vueda.user.migration_generation.operations`. The function names stay the same._
