- **`makeworkflowmigrations` names a state permission's group as the write recorded it**:
    - A generated workflow migration now names each state permission's group by the name that the group had at that write. Before, a migration generated after a group rename put the group's new name in `group_id`, even for writes made under the old name. Applying such a migration can fail to find the group, or can match a different group that holds that name.
      _If you renamed a group after writing state permissions for it, check the workflow migrations that you generated since then. Each `group_id` name should match the `historical_group_name` beside it._
