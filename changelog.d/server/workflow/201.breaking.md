- **Bulk execute-transition responses hold each object under `objects`**:
    - The `200`, the `409`, and the `400` for a refused object now hold `target_state` and `objects`. `objects` holds each object's `state` before the run, keyed by object id, with the result in a `200` and `errors` in a `400`. An unknown `transition_code` now returns `400` with a `transition_code` error instead of an error for each object.
      _Code that reads a bulk response or a bulk `400` by object id at the top level must read `objects` instead. See [Read a Bulk Response](../../guides/transition-ux-and-redirects.md#read-a-bulk-response)._
