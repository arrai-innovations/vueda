- **Wildcards and dotted names in `e` on writes**:
    - A `POST`, `PUT`, or `PATCH` answered `400` with `Invalid expands.` for a dotted name such as `e=customer.user`, and for `e=*` or `e=~all` when the write action had no permit list. A write now checks `e` with the rules and messages of a read, and its response expands these names as a read does.
    - Only the first level of each name changes how the body is read, and a wildcard changes nothing there.
