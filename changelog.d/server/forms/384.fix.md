- **Multipart saves with nested files and values**:
    - VUEDA viewsets decode the client's JSON multipart fields and restore files at their nested paths before validation, preserving arrays, objects, nulls, and empty collections.
    - Existing multipart clients remain supported, and invalid file manifests return `400`.
      _Deploy this server support before the updated client; custom DRF views need the [multipart mixin and standard parser](/core-concepts/crud-adapter-layer#server-support)._
