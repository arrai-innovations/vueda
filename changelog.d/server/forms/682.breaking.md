- **`e` on writes that send nested objects**:
    - `e=*` on a write action with a permit list read each permitted relation as a nested object, and made an expand-only name, such as an alias with its own `source`, a field of the body. It now reads those relations as primary keys, and answers `400` for an expand-only name in the body.
    - A custom action that calls `is_valid()` now answers `400` for an `e` name that its permit list leaves out, where it dropped the name before.
      _Name each relation that the body sends as a nested object in `e`, as in `e=customer,*`, and send a custom action only the names that its permit list holds._
