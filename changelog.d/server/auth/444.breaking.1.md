- **who-is `auth_pending_flow` (`vueda.user/who-is/`)**:
    - who-is returns `auth_pending_flow`, the flow the session owes, or `null` when none is pending. A signed-in user whose session is not recent gets `mfa_reauthenticate` or `reauthenticate`, and an anonymous session gets the stage a sign-in waits at, such as `mfa_authenticate`. It replaces `recently_logged_in`, which is removed.
      _Check `auth_pending_flow` for `null` where you read `recently_logged_in`; a custom `REST_AUTH["USER_DETAILS_SERIALIZER"]` must include the field._
