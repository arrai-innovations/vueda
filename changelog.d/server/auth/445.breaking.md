- **allauth headless routes under `vueda.user/_allauth/`**:
    - `vueda.user.urls` no longer mounts any allauth headless route, so every path under `vueda.user/_allauth/` returns 404, including `config`, `auth/signup`, `auth/password/reset`, `account/email`, and `account/authenticators/totp`. They let a caller create accounts, add email addresses, reset or change passwords, and add or remove a TOTP authenticator outside VUEDA's own views. Recovery codes moved from `_allauth/browser/v1/account/authenticators/recovery-codes` to `vueda.user/2fa/recovery-codes/`.
      _Call `vueda.user/2fa/recovery-codes/` for recovery codes; for any other route, use the matching VUEDA endpoint or mount the allauth view in your own URLconf._
