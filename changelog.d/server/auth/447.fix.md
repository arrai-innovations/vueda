- **Removing 2FA devices (`TOTPDeviceViewSet` destroy)**:
    - Two-factor authentication now turns off only when the user has no devices left. Before, a bulk delete padded with a duplicate or unknown key could turn 2FA off and delete the user's remaining devices.
    - Deleting every device now always turns 2FA off. Before, extra unknown keys in the request left 2FA active with no device to send a code to.
