- **`Retry-After` readable by cross-origin clients (`CORS_EXPOSE_HEADERS`)**:
    - `CORS_EXPOSE_HEADERS` now includes `retry-after`, so a browser client on another origin can read how long a 429 response asks it to wait.
      _If your project replaces the whole `CORS_EXPOSE_HEADERS` list, add `retry-after` to it._
