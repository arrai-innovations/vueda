- **Rate limits on code sends, forgot password, and password change (`vueda.user/totp_code/`, `vueda.user/totpdevice/setup/`, `vueda.user/forgot-password/`, `vueda.user/change_password/`)**:
    - `totp_code/` and `totpdevice/setup/` sent an email or SMS code on every request with no limit. They now allow 5 codes an hour for each account and method (`totp_send_user`), `totpdevice/setup/` also allows 5 an hour for each email address or phone number (`totp_send_destination`), and both answer 429 with no code sent once a limit is used up.
    - `forgot-password/` now allows 20 requests an hour from one client IP address (`forgot_password`), and `change_password/` allows 5 attempts a minute for each user (`change_password`), so a signed-in session cannot guess the current password.
      _Behind a reverse proxy, set `ALLAUTH_TRUSTED_PROXY_COUNT` or `ALLAUTH_TRUSTED_CLIENT_IP_HEADER`, or every client shares the proxy's address and its forgot-password limit. Show a "try again later" message when these endpoints answer 429. See [Configure the Cache and Sessions](../../guides/configure-cache-and-sessions.md#rate-limited-auth-endpoints) for each limit and the setting that changes it._
