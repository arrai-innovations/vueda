- **Rate limits on code sends and password change (`vueda.user/totp_code/`, `vueda.user/totpdevice/setup/`, `vueda.user/change_password/`)**:
    - `totp_code/` and `totpdevice/setup/` sent an email or SMS code on every request with no limit. They now allow 5 codes an hour for each account and method (`totp_send_user`), `totpdevice/setup/` also allows 5 an hour for each email address or phone number (`totp_send_destination`), and both answer 429 with no code sent once a limit is used up.
    - `change_password/` now allows 5 attempts a minute for each user (`change_password`), so a signed-in session cannot guess the current password.
      _Show a "try again later" message when these endpoints answer 429. See [Configure the Cache and Sessions](../../guides/configure-cache-and-sessions.md#rate-limited-auth-endpoints) for each limit and the setting that changes it._
