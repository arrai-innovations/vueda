- **Password reset endpoints routed by `vueda.user`**:
    - `vueda.user.urls` routes `VuedaForgotPasswordView` and `VuedaResetPasswordView` at `vueda.user/forgot-password/` and `vueda.user/reset-password/`, named `forgot_password` and `reset_password`.
      _If your project routes these views itself, remove those routes and use the `vueda.user` ones, which the client's default URLs call._
