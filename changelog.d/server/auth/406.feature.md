- **Password reset endpoints routed by `vueda.user`**:
    - `vueda.user.urls` routes `VuedaForgotPasswordView` and `VuedaResetPasswordView` at `vueda.user/forgot-password/` and `vueda.user/reset-password/`, named `forgot_password` and `reset_password`.
      _If your project routes these views itself, remove those routes and use the `vueda.user` ones, which the client's default URLs call._
    - `forgot-password/` allows 20 requests an hour from one client IP address (`forgot_password`) and answers 429 once that limit is used up.
      _Behind a reverse proxy, set `ALLAUTH_TRUSTED_PROXY_COUNT` or `ALLAUTH_TRUSTED_CLIENT_IP_HEADER`, or every client shares the proxy's address and its forgot-password limit. See [Configure the Cache and Sessions](../../guides/configure-cache-and-sessions.md#rate-limited-auth-endpoints) for the setting that changes the limit._
