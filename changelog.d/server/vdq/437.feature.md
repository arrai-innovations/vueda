- **Twilio and Anymail status updates for queue items with no stored provider ID (`VDQ_EMAIL_TRACKING_STRATEGY`)**:
    - VDQ now sends each queue item's key with the message, so a status update that arrives before VDQ stores the provider ID still finds its item. `VDQ_EMAIL_TRACKING_STRATEGY` selects how an email carries the key: in Anymail `metadata` by default, or not at all with `vueda.vdq.tracking.EmailTrackingStrategy`. See [Matching a status update to its queue item](/core-concepts/vdq-and-background-work#matching-a-status-update-to-its-queue-item).
      _On an ESP that accepts no metadata, select `vueda.vdq.tracking.EmailTrackingStrategy`. Otherwise VDQ builds every email twice and logs the retry at info level._
