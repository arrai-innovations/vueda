- **Supported Python, Django, and DRF versions**:
    - The `vueda` package now requires Python 3.12 to 3.14, Django 6.1 (`>=6.1.1,<6.2`), and Django REST framework 3.16 or later. Python 3.11, Django 5.2, and Django 6.0 are no longer supported.
      _Move your project to Python 3.12 or later and Django 6.1 before you upgrade VUEDA._
