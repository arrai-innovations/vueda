- **`drf-flex-fields` replaced by `drf-flex-fields2`**:
    - VUEDA now depends on `drf-flex-fields2`, the maintained fork, which installs the `rest_flex_fields2` module and reads the `REST_FLEX_FIELDS2` setting. Its package root exports nothing, so imports name a submodule. The `e`, `f`, and `om` query parameters and expand behavior are unchanged.
      _Rename a `REST_FLEX_FIELDS` setting override to `REST_FLEX_FIELDS2`. Import serializers from `rest_flex_fields2.serializers`, views from `rest_flex_fields2.views`, constants such as `WILDCARD_VALUES` from `rest_flex_fields2.config`, and helpers such as `split_levels` from `rest_flex_fields2.utils`._
