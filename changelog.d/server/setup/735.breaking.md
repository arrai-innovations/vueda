- **`django-allauth` version**:
    - The server package now requires `django-allauth[mfa]==65.23.0` instead of any release from 65.14.1. This release includes allauth's security fixes up to 65.23.0, including the fix that stops a TOTP code from being reused within the tolerance window.
      _Remove other `django-allauth` version constraints from your project, or set them to 65.23.0._
